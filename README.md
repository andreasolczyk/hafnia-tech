# Hafnia Technologies

Website for [hafnia.tech](https://hafnia.tech): technology concepts built in Copenhagen.

A single static page hosted on GitHub Pages. No build step and no outside requests:
the font is embedded in `index.html`, and the logo animation is plain JavaScript and SVG.

| File | What it is |
| --- | --- |
| `index.html` | The page, with the liquid logo animation |
| `CNAME` | Tells GitHub Pages the site lives at hafnia.tech |
| `favicon.ico`, `favicon.svg` | Browser tab icons |
| `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Home-screen icons |
| `site.webmanifest` | App name and icons for phones |
| `link-preview-1200x630.png` | Image shown when the link is shared |
